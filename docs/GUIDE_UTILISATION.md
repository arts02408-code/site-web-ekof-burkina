# Guide d'utilisation EKOF V1

## Pour les visiteurs

1. Ouvrir l'accueil et choisir « Découvrir le catalogue ».
2. Rechercher un produit, choisir une catégorie ou trier les résultats.
3. Ouvrir une fiche pour consulter l'image, le prix et les informations disponibles.
4. Choisir le bouton WhatsApp pour préparer une demande de disponibilité ou de commande.
5. Confirmer directement avec EKOF le prix définitif, le stock, les modalités, le paiement et la livraison.

Les liens WhatsApp contiennent un message prérempli. Tant que le numéro officiel n'est pas renseigné, WhatsApp demande de choisir le contact EKOF. Le site n'enregistre pas la demande et ne confirme pas une vente.

## Pour parcourir et présenter le site

- Double-cliquer sur `index.html` ; aucune commande ni installation n'est requise pour le parcourir.
- Ouvrir la page d'accueil, puis présenter le catalogue, la recherche, les filtres, les fiches produit et les pages EBEN.
- Montrer la page EBEN Production et le parcours de devis.
- Sur un smartphone ou l'émulation mobile du navigateur, tester le menu et l'affichage produit.
- L'aperçu utilise un instantané local du catalogue indiqué par un bandeau ; les images requièrent Internet et prix/stocks restent à confirmer.
- Expliquer clairement que le site n'inclut aucun paiement en ligne et que les coordonnées manquantes doivent être confirmées avant publication.

Pour voir les mises à jour du catalogue en direct, utiliser le serveur optionnel décrit dans `CONFIGURATION_EKOF.md`.
